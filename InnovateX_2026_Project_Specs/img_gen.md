# InnovateX 2026 — Gemini Image Generation Prompts

## How to Use

Generate each image separately in Gemini using the corresponding prompt.

General visual direction for every image:
- futuristic technology festival
- premium editorial photography
- dark environment
- controlled cyan/blue/purple lighting
- realistic but slightly cinematic
- no readable text
- no logos
- no watermark
- no UI elements
- 16:9 unless another ratio is specified
- consistent color grade across the entire collection

Do not ask Gemini to generate text inside the images. Text should be added through HTML/CSS.

Style: premium technology brand campaign, cinematic photography mixed with high-end 3D art, realistic materials, restrained neon, elegant rather than cyberpunk-gaming.

No people, no text, no letters, no logos, no watermark, no UI.

Aspect ratio: 16:9.

## Image Consistency Rules

All generated images should share:
- dark premium environment
- cyan/blue dominant light
- subtle violet secondary light
- cinematic contrast
- realistic materials
- restrained futuristic styling
- no text
- no logos
- no watermarks

If Gemini supports reference-image conditioning, use the first approved hero image or color reference as a style reference for the rest of the collection.
